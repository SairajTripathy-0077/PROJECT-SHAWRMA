## 🎯 System Persona Template for LLMs
Copy and paste this system prompt block before requesting new ideas:

```text
You are a Principal Optical Communications Engineer & Senior Computer Vision Architect specializing in Free-Space Optical Communications (FSOC) and Pointing, Acquisition, and Tracking (PAT) systems for LEO/GEO satellite mega-constellations and deep-space laser links.

You are collaborating on the FSOC PAT Simulator codebase:
- Stack: React Three Fiber (Three.js / WebGL) + Tailwind CSS + Python OpenCV (5.x) + 2D Kalman Filter + Dual-Axis PID + Tauri v2 IPC.
- Core Simulation: 30 FPS closed-loop optical beacon tracking with mechanical platform jitter, atmospheric scintillation, and turbulence dropouts.
- Zero-Regression Rule: Any new proposal must maintain 100% backward compatibility with existing interfaces, JSON IPC contracts, and simulation trajectories.

Your role is to propose mathematically rigorous, technically feasible, and state-of-the-art innovations with concrete formulas, architectural designs, and implementation plans.
```

## 🚀 The 4-Tier Innovation Matrix

### Tier 1: Advanced Computer Vision & Deep Learning Tracking
```text
Prompt 1.1: Deep Optical Flow & Transformer-Based Tracking
"Design a deep learning feature extractor (e.g. lightweight MobileNetV4 or Optical Flow Transformer) to replace standard OpenCV intensity thresholding for tracking optical beacons obscured by dense cloud scattering and solar glare. Detail model quantization (ONNX/TensorRT) to fit within the <10ms per frame latency budget."

Prompt 1.2: Sub-Pixel Super-Resolution & Astigmatic Spot Fitting
"Provide an algorithm in Python/OpenCV for 2D Elliptical Gaussian Surface Fitting and Astigmatic Beam Profiling to detect not only the spot centroid (x, y) with 0.05-pixel accuracy, but also beam divergence angle and wavefront tilt."
```

### Tier 2: Space Optics & Atmospheric Physics Modeling
```text
Prompt 2.1: Kolmogorov & Non-Kolmogorov Atmospheric Phase Screens
"Formulate a GPU-accelerated (Three.js WebGL shader) atmospheric turbulence simulation based on the Kolmogorov / Von Kármán refractive index structure parameter (Cn^2), simulating dynamic beam wander, beam spreading, and spatial scintillation."

Prompt 2.2: Spacecraft Microvibration & Orbital Dynamics
"Model realistic satellite reaction-wheel microvibrations (harmonic sinusoidal + broad-band random PSD) and orbital line-of-sight Doppler drift for LEO-to-Ground optical downlinks."
```

### Tier 3: Estimation & Multi-Stage Control Architectures
```text
Prompt 3.1: Coarse Gimbal + Fine Fast-Steering Mirror (FSM) Dual-Stage Control
"Architect a dual-stage PAT control loop:
1. Coarse Gimbal (Large range ±180°, low bandwidth ~5 Hz, stepper/servo)
2. Fast-Steering Mirror (Piezo/voice-coil, fine range ±1°, high bandwidth >500 Hz).
Provide the decoupled control transfer functions and handover logic."

Prompt 3.2: Reinforcement Learning (PPO) Adaptive Tracking Agent
"Formulate a Reinforcement Learning environment (Gymnasium/TorchRL) where a PPO agent learns adaptive gimbal velocity damping under severe non-linear turbulence, replacing conventional PID gain tuning."
```

### Tier 4: Digital Twin UI, Space Constellations & Link Budgets
```text
Prompt 4.1: Real-Time Optical Link Budget & BER / SNR Calculator
"Design a real-time communications telemetry widget calculating received optical power (dBm), Signal-to-Noise Ratio (SNR), Bit Error Rate (BER), and Link Margin based on transmitter laser power (e.g., 5W @ 1550nm), receiver aperture (20cm), and pointing error jitter."

Prompt 4.2: 3D Multi-Satellite Constellation Link Routing
"Create a 3D Earth orbit visualization in React Three Fiber showing dynamic inter-satellite laser crosslinks (ISLs) between orbiting satellites, with visual beam lock status and automated handover switching."
```

## 📋 Evaluation Criteria for LLM Responses
When evaluating ideas generated by LLMs, verify:
1. **Computational Feasibility**: Can the algorithm execute within the $\le 33.3\text{ms}$ budget at 30 FPS?
2. **Mathematical Soundness**: Are the physics formulas (Fresnel diffraction, Gaussian beam propagation, state-space matrices) verified?
3. **Architectural Cleanliness**: Does the design preserve the existing JSON IPC contract and dual-mode desktop/browser fallback?
